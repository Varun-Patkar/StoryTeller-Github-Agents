# Concept: System Shop & Barter Economy

> id: concept-system-shop-barter-economy | type: concept | canonicity: original

## Overview
The rules of how Theron turns value into power. Everything in the AC universe is for sale; the price is anything valuable. This concept exists so the "power fantasy" never becomes a free lunch: every upgrade is earned, budgeted, and traded for.

## Tiers
- **Basics (cheap):** rations, clean water, medicine, common weapons, rope, oil.
- **Edges (moderate):** better gear, minor consumable boosts, information.
- **Game-changers (very expensive):** concentrated Isu blood, Pieces of Eden, permanent attribute increases, Isu knowledge/blueprints, longevity/immortality.

## Currencies
Drachmae -> orichalcum -> (discovered later) Isu artifacts themselves, which the shop values enormously. This is how Theron eventually affords immortality: by trading up lesser relics he recovers across Greece.
