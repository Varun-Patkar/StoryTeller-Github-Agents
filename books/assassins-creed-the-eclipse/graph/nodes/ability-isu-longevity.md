# Ability: Isu Longevity

## Overview
Refined Isu biotechnology developed by the Eclipse that can greatly extend a proven member's lifespan. Some members live centuries; others serve a single lifetime. Every recipient chooses the burden willingly.

## Canon
Extrapolated from canon longevity artifacts (the Staff) and Isu biotech.

## AU Divergence
How the Eclipse keeps legendary operatives (like the Kenways) active across eras. Distinct from the Staff, which is a single unique artifact.
