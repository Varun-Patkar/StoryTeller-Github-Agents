# Concept: Balance Philosophy

## Overview
The Eclipse pursues Balance: not neutrality, not indecision, but the active discipline of preventing any single philosophy from becoming absolute. Freedom without restraint becomes chaos; Order without compassion becomes tyranny. Whenever one side grows too dominant, the Eclipse quietly intervenes.

## Canon
INVENTED, though it resonates with Bayek's canon line about balancing freedom and innocent lives.

## AU Divergence
Creed: 'No truth is absolute. No order eternal.' The eclipse symbol means neither light nor dark should fully cover the other. Continuity, not victory, is the goal.
