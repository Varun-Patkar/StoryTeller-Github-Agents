# Arc VI: The Game of Gods

## Overview
A protracted strategic conflict between Cain and Loki (Basim). Neither can move openly; every action risks humanity's future. A chess match across generations.

## Canon
Built on canon Loki/Basim lore and his imprisonment/freeing.

## AU Divergence
Elevates Loki to Cain's true equal and defines the story's intellectual climax.
